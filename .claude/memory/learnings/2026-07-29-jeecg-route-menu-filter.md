# JeecgBoot 动态权限守卫按菜单过滤路由（新页面 404 根因）

**场景**：新增前端页面，路由已注册（routes/modules/mes.ts），直接访问 URL 却 404。

**根因**：jeecgboot-vue3 的 permissionGuard 在登录后按**后端菜单权限**重建可访问路由表——没有菜单支撑的静态路由会被移除。之前所有页面都有菜单（MesMenuRegistry 注册）所以从未踩到；Gallery 展示页是第一个"只要路由不要菜单"的页面，立刻中招。

**排查路径**：路由结构正确 → Vite 重启无效 → 静态路由其实已加载但被守卫过滤 → 注册菜单后恢复。

**正确做法**（两选一）：
1. **业务页面**：路由 + MesMenuRegistry 菜单（标准做法，id+perms 双写）
2. **纯工具/展示页**：如果确实不想要菜单入口，需要研究守卫白名单（本项目未验证）；当前约定是**一律注册菜单**（放"开发工具"分组即可）

**触类旁通**：以后"路由明明注册了但 404" → 第一怀疑菜单注册，而不是路由本身。

**实证**：2026-07-29 Gallery 404 修复（commit f865892）。
