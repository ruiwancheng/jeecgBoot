# /onboard [目标]

交互式环境配置向导。AI 检测操作系统，逐项核对所需工具，缺什么给什么安装命令。

## 目标
- `minimal` — 仅前端
- `standard` — 前后端
- `full` — 完整 harness（+ MCP + Orca）
- 不指定 → 询问用户选级

## 流程

使用 `onboard` 技能获取：工具清单（分级）、OS 适配安装命令矩阵、版本检测方法、验证标准、报告模板。

### 1. 检测 OS

按技能中的 OS 检测方法确定平台。

### 2. 逐项核对

按目标级别对应的工具清单，逐项检查安装+版本达标情况。

### 3. 生成安装清单

缺失/版本不足的工具 → 按技能中的 OS 适配矩阵输出安装命令。已就绪的项不重复输出。

### 4. 用户执行 + AI 验证

用户执行安装后，AI 重新检查确认。通过一项进入下一项。

### 5. 输出环境就绪报告

全部通过后，按技能模板输出。按级别引导用户下一步。
