# /business-description [文本]

将技术回复转换为业务人员能理解的中文。一次性使用，不影响后续对话风格。

## 流程

### 1. 加载领域知识

使用 `business-description` 技能获取：翻译规则、三段式模板、术语锚定策略、边界定义。

### 2. 确定翻译目标

- **有参数**：翻译参数中提供的文本
- **无参数**：翻译当前会话上一条 AI 回复（取 `assistant` 角色的纯文本，跳过 `tool_use`/`tool_result` 块。若上一条无文本，向上回溯至最近一条有文本的 `assistant` 消息）
- **无历史 + 无参数**：提示"当前没有可翻译的回复，请粘贴技术文本或先进行一轮对话"

### 3. 执行翻译

按技能中的翻译规则和三段式模板输出。

### 4. 输出

只输出翻译结果，不加开场白、回顾、结束语。
