# /deep-inspect

对指定模块执行深度巡检，含性能基准测试、视觉回归检测和无障碍审计。

## 前置条件

首次运行前需要初始化基线。使用 `deep-inspect` 技能获取：完整检查清单（k6/Playwright/后端/前端/基线目录）、首次运行建立基线规则。

首次运行行为：仅建立基线数据，不输出 PASS/FAIL 判定。基线建立后下次运行进行趋势对比。

## 流程

使用 `deep-inspect` 技能获取：性能测试脚本模板（k6+curl 降级）、视觉采集协议（Playwright+pixel-diff）、无障碍检查清单（WCAG 2.2 AA）、基线格式+趋势对比规则、报告模板。

### 1. 确定巡检范围

- 指定模块 → 只巡检该模块
- 未指定 → 巡检当前活跃项目（从 `features.json` 读取）
- 高风险模块优先（按 git diff 频率和测试失败率排序）

### 2. 并行执行三步检查

**性能基准**：读端点 → 执行基准测试 → 与上次基线对比 → 存储新基线

**视觉证据**：导航关键页面（列表/新增/编辑/详情）→ 三视口截图 → pixel-diff 对比

**无障碍审计**：axe-core 扫描 → WCAG 分类 → 输出修复优先级

### 3. 输出报告 + 保存产物

按技能模板输出报告，含三步结果+趋势对比+P0-P3 修复建议。产物存技能定义的目录路径。

## 建议触发频率

| 场景 | 频率 |
|------|------|
| 活跃开发中模块 | 每周 1 次 |
| 稳定维护模块 | 每 2 周 1 次 |
| 发布前 | 必须执行 |
| 全量级变更后（≥5 文件） | 建议执行 |
