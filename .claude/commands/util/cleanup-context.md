# /cleanup-context

长会话上下文膨胀时，生成一份结构化"记忆卡片"——下一个 AI 拿到它，无需回看任何历史对话就能直接干活。

## 流程

使用 `cleanup-context` 技能获取：记忆卡片模板、输出后提示模板、质量门控规则、状态提取规则。

### 1. 总结当前会话状态

按技能中的状态提取规则，提取：
- **当前阶段**（brainstorm / plan / implement / verify / debug）
- 正在做的任务/需求
- 已做的关键决策及原因
- 已排查/排除的方向
- **下一步[自动执行]**：按技能中的**质量门控规则**——必须含文件路径，否则重写

### 2. 读取项目状态

按技能定义读取 `progress.md` + git 待部署提交列表。

### 3. 合并输出记忆卡片

按技能中的模板输出——会话状态放最前，规则压缩到关键提醒。

### 4. 输出后提示

按技能中的提示模板输出使用指引。
