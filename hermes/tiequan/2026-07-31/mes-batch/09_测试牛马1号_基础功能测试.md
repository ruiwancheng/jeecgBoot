# 09_测试牛马1号_基础功能测试 — MES 批次管理审计

**审计角色**: 测试牛马1号 — 基础功能测试  
**审计日期**: 2026-07-31  

## 审计发现

### P0-4 ledger.api.ts 缺少 getExportUrl 导出（P0）
- **文件**: `ledger.api.ts:1-7`
- **描述**: `ledger.api.ts` 只导出了 `queryLedgerList`，但 `ledger.index.vue` 的 `useListPage` 中 `exportConfig: { url: getExportUrl }` 引用了未导出的 `getExportUrl` → 前端运行时 `Uncaught ReferenceError: getExportUrl is not defined` → 导出按钮报错
- **修复建议**: `ledger.api.ts` 增加：`export function getExportUrl() { return '/mes/batch/ledger/exportXls' }`

### P0-1 批次号取号无锁（P0）
- **文件**: `MesBatchServiceImpl.java:35`
- **描述**: count+1 无锁并发重号
- **修复建议**: 见总报告

### P1-6 批次删除未级联处理库存和流水（P1）
- **文件**: `MesBatchController.java:62-65`; `MesBatch.java:82 @TableLogic`
- **描述**: 删除批次只是软删除主档，`MesBatchInventory` 和 `MesBatchLedger` 中关联的记录不变。如果之后重新创建同物料批次（复用旧batchId？不，新ID），流水依然关联旧批次。另外软删除的批次占用了 `uk_batch_no_del` 索引
- **修复建议**: 删除前检查是否有库存（qty>0），有库存时禁止删除；至少级联删除关联的 ledger 记录

### P2-8 新增批次后前端 batchNo 无法看到（P2）
- **文件**: `BatchMasterDrawer.vue`, `master.data.ts:34-42`
- **描述**: formSchema 中 batchNo 设为 `disabled: true`，新增保存后弹窗关闭，列表刷新才显示新 batchNo。用户看不到"保存后生成了什么批次号"
- **修复建议**: 新增成功后 message 显示批次号：`message.success(\`批次创建成功: \${response.batchNo}\`)`

### P3-4 tab 面板无权限码保护（P3）
- **文件**: `batch/inventory/index.vue`, `batch/ledger/index.vue`
- **描述**: tab 面板组件只在父路由上设了菜单权限，组件本身没有 `v-if` 权限控制。虽然 Shiro 在 Controller 层拦截，但前端组件不隐藏无权限的 tab
- **修复建议**: 不阻塞，P3 建议
