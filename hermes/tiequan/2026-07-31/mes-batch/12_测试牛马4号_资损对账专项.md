# 12_测试牛马4号_资损对账专项 — MES 批次管理审计

**审计角色**: 测试牛马4号 — 资损对账专项  
**审计日期**: 2026-07-31  

## 审计发现

### P0-5 stockOutFifo 批次出库成本被丢弃（P0）
- **文件**: `MesSalesOutboundServiceImpl.java:133`; `ProductionPickingServiceImpl.java:132`
- **描述**: `batchInventoryService.stockOutFifo(...)` 返回 `List<BatchOutDetail>`，含 `batchId/batchNo/qty/unitCost`。两端调用方都没有接收返回值。销售出库明细的 unitCost 字段不受赋值 → 销货成本为 null/0 → 毛利虚高
- **修复建议**: 
  ```java
  List<BatchOutDetail> batchCosts = batchInventoryService.stockOutFifo(...);
  // 将批次出库成本写入明细
  item.setUnitCost(batchCosts.stream()
      .map(BatchOutDetail::unitCost)
      .reduce(BigDecimal.ZERO, BigDecimal::add)
      .divide(new BigDecimal(batchCosts.size()), 4, RoundingMode.HALF_UP));
  ```

### P0-1 批次号取号无锁导致重号 → 创建失败 → 入库不完整（P0）
- **文件**: `MesBatchServiceImpl.java:35`
- **描述**: 并发创建批次 → 重号 → DuplicateKeyException → 事务回滚 → 库存不增，但主库存已增（主库存 stockIn 在 createBatch 之前执行）→ 业财数据不一致
- **修复建议**: 见总报告

### P1-1 多次入库 unitCost 不更新（P1）
- **文件**: `MesBatchInventoryServiceImpl.java:39-40`
- **描述**: 第一批入库成本 A 元创建库存行，第二批入库成本 B 元但不更新 unitCost → 出库按 A 元计算成本：
  - 涨价趋势：出库成本偏低 → 利润虚高
  - 跌价趋势：出库成本偏高 → 利润偏低
- **修复建议**: 每次入库后按移动加权平均更新：`newUnitCost = (oldQty*oldCost + inQty*inCost) / (oldQty + inQty)`

### P1-2 主库存与批次库存无一致性校验（P1）
- **文件**: 跨 `MesInventoryServiceImpl` 和 `MesBatchInventoryServiceImpl`
- **描述**: 
  - 主库存按 (material_id, warehouse_id) 维度
  - 批次库存按 (batch_id, warehouse_id) 维度
  - 理论: `SUM(批次.qty) FOR material_id, warehouse_id == 主库存.qty`
  - 实际: 无此校验 → 任何代码错误或异常回滚都会导致不一致且长期不被发现
- **修复建议**: 新增 job/trigger：定期执行 `SELECT ... SUM(inv.qty) GROUP BY ... HAVING SUM(inv.qty) != batchSum` → 发现差异告警

### P2-3 完工入库批次成本为 NULL（P2）
- **文件**: `CompletionReceiptServiceImpl.java:137-141`
- **描述**: `batchService.createBatch(..., null, null, null)` — unitCost 传 null。完工入库的批次成本缺失
- **修复建议**: 生产完工入库应传入当前物料移动平均成本 `materialService.getById(item.getMaterialId()).getMovingAvgCost()`
