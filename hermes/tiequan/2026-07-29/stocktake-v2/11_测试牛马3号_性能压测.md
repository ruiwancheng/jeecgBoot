# 11_测试牛马3号_性能压测

> 审计对象：MES 盘点单 V2
> 审计日期：2026-07-29

## 新增 N+1 查询

### refreshItems 全量重写 ✅
1 快照 SQL + 1 DELETE + N INSERT + 1 UPDATE(snapshotTime)。500 行=一次事务。~100ms ✅

### 前端批量添加物料 N+1 🔴 P1
```js
for (const m of materials) {
    const res = await queryInventoryList({ materialId: m.id, warehouseId: wh, pageNo: 1, pageSize: 1 });
    // N 次 HTTP 请求！
}
```
50 个物料=30s 延迟 🔴 P1

### 展开行 N+1 🔴 P1
```js
// StocktakeItemsSubTable onMounted
const doc = await queryStocktakeById({ id: props.docId });
const materials = await Promise.all(ids.map((id) => queryMaterialById({ id })));
```
N 个物料 = N 次 API。虽已有 `materialId_dictText` 可用，但子表为了显示规格型号 `spec`、物料编码 `code` 仍需 batch 查询。🔴 P1

### loadMaterialMap N+1 🔴 P1
Drawer 编辑时 `loadMaterialMap()` 逐物料 `queryMaterialById` = N 次 API。100 行全盘 → 100 次 HTTP 🔴 P1

## 索引

## 结论
V2 新增了 3 个明显的 N+1 查询。3 P1（批量添加/展开行/loadMaterialMap N+1 查询 + create_time 索引）。
