## 🟡 发现

| # | 问题 | 等级 |
|---|------|:--:|
| T1-1 | **没有查询所有入库单的公共接口**（如 `selectPage`/下拉用），其他模块无法通过 API 引用入库单 → 需要引用时只能直接查表 | 🟡 P2 |
| T1-2 | **无导入接口**（Excel 批量导入） | 🟡 P3（Phase 2 可加） |
| T1-3 | **明细查询用 `queryOtherInById` API**（`queryById` 端点），但 `OtherInItemsSubTable` 每次都根据 `docId` 重新调一次完整接口 | 🟡 P2（应提供独立的 `/items` 子表端点，减少数据传输量） |

## 结论

增删改查 + 状态流转全部正确，防御完备。3 个 P2/P3 建议。

**风险汇总：0 P0 / 0 P1 / 3 P2**
