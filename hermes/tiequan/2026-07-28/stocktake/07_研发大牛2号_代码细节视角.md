## 🟡 硬编码问题
```java
// L248-249 in getCurrentUsername():
LoginUser user = (LoginUser) SecurityUtils.getSubject().getPrincipal();
return user != null ? user.getUsername() : "admin";
```
admin 硬编码为默认值。如果 SecurityUtils 返回 null（未登录/会话过期）→ 操作者显示为 "admin" → 审计链失真。
- 同样模式也用在 OtherStockIn/Out → 项目模式 ✅（全模块一致）
- 但 `"admin"` 用户名在对多租户环境有歧义 — 🟡 P3

## 🟡 `getFieldsValue().warehouseId || currentWarehouseId.value` 冗余
```js
// StocktakeDrawer L94-96:
const wh = getFieldsValue().warehouseId || currentWarehouseId.value;
if (!wh) { message.warning('请先选择仓库'); return; }
currentWarehouseId.value = wh; // ← 每次添加行都重置
```
`currentWarehouseId` 在编辑时从 `o.warehouseId` 传入（L84），但添加行时又会被 `getFieldsValue()` 覆盖。

如果用户在两个仓库之间切换 → currentWarehouseId 和 getFieldsValue 不一致 → 选中第一个仓库添加的行 → 切换到第二个仓库 → bookQty 仍来自第一个仓库 → 🟡 P2（低概率）
