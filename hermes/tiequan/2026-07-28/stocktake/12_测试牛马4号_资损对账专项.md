# 12_测试牛马4号_资损对账专项

> 审计对象：MES 盘点单模块
> 审计日期：2026-07-28

## 金额流全链路

### 盘点 → 出入库 → 库存 → 台账

```
实盘差异 → diffQty × unitCost → diffAmount
  → 生成入库单(如果diff>0) → saveWithItems → validate(amount = qty×unit_cost, setScale 2)
    → audit → updateMovingAvgCostOnStockIn → stockIn(qty, unitCost, amount) → 台账(inAmount)
  → 生成出库单(如果diff<0) → saveWithItems → validate(amount)
    → audit → stockOut(qty, unitCost, amount) → 台账(outAmount)
```

### 对账矩阵

| 对账关系 | 数据源 A | 数据源 B | 可对？ |
|---------|---------|---------|:--:|
| 盘点差异金额 | SUM(c_mes_stocktake_item.diff_amount WHERE takeId=X) | c_mes_stocktake.total_diff_amount | ✅ calcAndSaveItems 逐行累加 |
| 盘点→入库 | diffQty(盘点详情) | SUM(qty)(入库行) | ✅ 同一事务，同一快照 |
| 盘点→出库 | |diffQty|(盘点详情) | SUM(qty)(出库行) | ✅ 同上 |
| 入库金额 | SUM(diffAmount)(盘点盘盈) | SUM(amount)(入库行) | ✅ validate 强制覆盖 |
| 出库金额 | SUM(|diffAmount|)(盘点盘亏) | SUM(amount)(出库行) | ✅ 同上 |
| 库存增减 | 入库审核量 | stockIn FOR UPDATE 后 current_qty | ✅ (继承) |
| 台账 | stockIn/Out 调用 | writeLedger(inAmount/outAmount) | ✅ (继承) |

### 🔴 P0：盘盈盘亏 unitCost=null → amount=0 静默

```java
// calcAndSaveItems L233:
BigDecimal cost = item.getUnitCost() != null ? item.getUnitCost() : BigDecimal.ZERO;
// L238:
item.setDiffAmount(diff.multiply(cost).setScale(2, RoundingMode.HALF_UP));
```

如果 `unitCost` 为 null → `cost=0` → `diffAmount=0` → 差异金额合计被低估。全盘快照中 `unitCost` 取自 `m.moving_avg_cost`（可为 null = 物料从未入库 → 成本 = 0 → 正确）。抽盘中用户可手工改 `unitCost` → null → 后端静默为 0 → 🟡 P2。

### 交叉检查：盘点差异金额合计 vs 出入库单总金额

```java
// 盘点 audit L162-163:
ii.setAmount(ii.getQty().multiply(item.getUnitCost() != null ? item.getUnitCost() : BigDecimal.ZERO)
    .setScale(2, RoundingMode.HALF_UP));
```

盘点生成的入库单 `amount` 使用 `item.getQty() × item.getUnitCost()`，其中 unitCost 来自盘点明细。**同一事务中**出入库单的 validate 会二次计算 `amount` — 以 validate 为准。两者用同一 unitCost 快照 → 金额一致 ✅

## 跨期对账

| 场景 | 对账方法 |
|------|---------|
| 盘点审核后生成的入库单 | `generatedInId` ↔ `c_mes_other_stock_in.id` ← 可追溯 |
| 盘点审核后生成的出库单 | `generatedOutId` ↔ `c_mes_other_stock_out.id` ← 可追溯 |
| 盘亏出库 → 台账 | 台账 `bizType='其它出库'` → `bizId` = 出库单 code → 再追溯到盘亏行 → `generatedOutId` ✅ |

## 结论
金额链可追溯到最终出入库单。仅 1 P2（unitCost=null 默认 0 的静默行为）。

**风险汇总：0 P0 / 0 P1 / 1 P2**
