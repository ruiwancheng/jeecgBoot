# 03_产品大佬1号_客户视角审计

> 审计对象：MES 盘点单模块
> 审计日期：2026-07-28

## 正向流程验证

### 全盘流程 ✅
```
新建盘点单(选仓库,全盘) → 后端自动快照全仓账面库存 → 保存 → 编辑录入实盘数 → 审核 → 差异行自动生成盘盈入库/盘亏出库并生效
```
- 创建时自动生成明细（`actual_qty` = 账面数），用户只改差异行 ✅
- 快照时间记录 `snapshot_time`，前端 alert 提示—用户清楚"差异以账面时点为准" ✅
- 审核后 `Modal.success` 展示结果摘要（盘盈入库单号/盘亏出库单号）✅

### 抽盘流程 ✅
```
新建(选仓库,抽盘) → 手工添加物料行 → 选物料时自动拉账面库存+移动平均成本 → 保存 → 审核
```
- `onMaterialChange` 同时预填 `book_qty`（调 inventory API）+ `unit_cost`（取 movingAvgCost）✅

### 操作体验 🟢
- 编辑状态下物料列只读（`<span>`），不需要改物料只改实盘数 ✅
- 差异行红色高亮（`color:#f5222d , fontWeight:600`）— 一眼看出异常 ✅
- 审核时有 popConfirm 二次确认 ✅

### 🟡 体验改进

| # | 问题 | 建议 |
|---|------|------|
| P-1 | **编辑时无法看到关联的出/入库单号** — `generated_in_id`/`generated_out_id` 有值但前端不展示 | 审核完成后在抽屉/详情页显示关联单据号 + 点击跳转 |
| P-2 | **全盘新建时提示"保存后自动快照"，用户可能以为点"确定"就什么都完成了** | 提示文案加"保存后在列表中点'录入实盘'进入编辑" |
| P-3 | **`stocktake.api.ts` 无 `exportXls` 导出端点** | 盘点单据应支持 Excel 导出（参考 otherIn/otherOut 模式） |

## 结论
全盘+抽盘双路径完整、差异可视化清晰。3 个体验级建议。0 P0/0 P1/3 P2。
