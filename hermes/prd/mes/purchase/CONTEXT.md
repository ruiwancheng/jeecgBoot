# MES 采购子域 — 上下文词典

> MES 采购管理子域的领域术语词典。
> **不含实现细节**（无字段名、表名、API 路径）。仅记录业务概念。

## Language

### 单据类型

**采购申请单**：采购需求方发起的物料申请单据。用于预算审批、内部立项。
_Avoid_: 请购单、采购需求单

**采购订单**：与供应商签订的采购合同单据。包含物料明细、单价、数量、含税/不含税金额。
_Avoid_: 采购合同、采购单

**采购收货单**：采购订单的实际到货记录。每行可关联采购订单明细的"已发数量"。
_Avoid_: 采购入库单、到货单

### 状态机（采购申请）

| 状态值 | 名称 | 说明 |
|:--:|------|------|
| 1 | 草稿 | 新建未提交，可编辑可删除 |
| 2 | 已提交 | 已提交待审批，采购员可审核 |
| 3 | 已通过 | 审核通过，**自动生成采购订单** |
| 4 | 已驳回 | 审核拒绝，终态-失败 |

### 状态机（采购订单）

| 状态值 | 名称 | 说明 |
|:--:|------|------|
| 1 | 草稿 | 新建未确认 |
| 2 | 待确认 | 已确认/待供应商确认 |
| 3 | 已确认 | 供应商确认 |
| 4 | 部分到货 | **进行中过渡态**（部分行已到货，部分未到） |
| 5 | 已到货 | 全部到货 |
| 6 | 已关闭 | 正常业务终态（与销售订单已关闭同色，green） |

**关键点**：采购订单的"部分到货"是**唯一的进行中过渡态**——既不是草稿/待确认（待处理），也不是已完成/已关闭（终态）。业务上采购员看到"部分到货"应该知道还要继续收货。

### 状态机（采购收货）

| 状态值 | 名称 | 说明 |
|:--:|------|------|
| 1 | 草稿 | 新建未入库 |
| 2 | 已入库 | 审核完成，**增加库存 + 重算物料移动平均成本** |

### 采购动作

**采购申请审核通过**：状态从"已提交"转到"已通过"，**自动生成一张采购订单**（草稿态），订单行复用申请单物料明细。
_Avoid_: 审批通过、申请通过

**采购收货审核**：状态从"草稿"转到"已入库"。**对每行物料**：增加库存（库存金额增加 = 收货数量 × 采购单价），调用 `updateMovingAvgCostOnStockIn` 重算物料移动平均成本（入库时才会重算，**出库不重算**——与销售出库对称）。
_Avoid_: 入库审核、收货审核

### 业务约束

**入库必填成本**：盘盈行（采购收货）成本不能为 0，否则入库金额为 0 导致物料移动平均成本被错误拉低。
_Avoid_: 零成本入库

**采购订单作为收货依据**：收货单必须关联采购订单；收货数量不能超过订单的"未到货数量"。这是状态机流转"待确认→部分到货→已到货"的物理依据。
_Avoid_: 收货数量校验

### 业务对偶

**采购申请 → 采购订单 → 采购收货** 构成完整链路。每一跳都通过"自动生成"或"审核触发"完成：
- 申请 audit → 订单（自动生成）
- 收货 audit → 库存 + 成本（联动）

**与销售链路对偶**：销售订单 → 发货单 → 销售出库。区别：
- 销售链路：出库不重算成本（销售出库按当时移动平均成本记账，详见 stock 子域 ADR 0001）
- 采购链路：入库会重算成本（采购入库按采购价加权平均计算新成本）

### 成本追溯

**移动平均成本（采购场景）**：每次采购入库时重算物料的加权平均成本。算法：新成本 = (剩余库存金额 + 本次入库金额) / (剩余数量 + 本次入库数量)。如果剩余库存为 0，则新成本 = 本次入库单价。

**采购价 ≠ 移动平均成本**：采购价是本次入库的单价，移动平均成本是物料维度的全局平均。两个值在系统中独立维护。
_Avoid_: 平均成本、加权成本（业务人员口语）

### 关联业务概念

**预算科目**：采购申请上的预算来源字段（财务记账用）。仅采购申请有，采购订单和收货沿用。
_Avoid_: 成本中心、预算项

**付款条款**：采购订单上的付款条件（货到付款/预付/分期等）。仅采购订单维护。
_Avoid_: 结算条款

**供应商**：采购业务的核心主体。三类单据都关联供应商，作为审计与对账维度。
_Avoid_: 厂商、客户（采购侧用供应商不用客户）
