# MES 库存子域 — 上下文词典

> MES 库存管理子域的领域术语词典。
> **不含实现细节**（无字段名、表名、API 路径）。仅记录业务概念。

## Language

### 单据类型

**其它入库单**：非采购、非生产原因产生的入库记录。用于盘盈、期初、归还等场景。
_Avoid_: 杂项入库、调整入库、其它入库

**其它出库单**：非销售、非生产领料原因产生的出库记录。用于盘亏、报废、领用等场景。
_Avoid_: 杂项出库、调整出库、其它出库

**盘点单**：周期性或临时性库存盘点作业的主单据。通过对比账面与实物产生盘盈或盘亏，自动生成对应的其它入库单或出库单。
_Avoid_: 库存核对表、库存盘点单、库存盘点

**盘点差异**：单行盘点中"实盘数 − 账面数"的差额。差额 > 0 为盘盈（生成入库单），< 0 为盘亏（生成出库单），= 0 无差异（不生成单据）。
_Avoid_: 盘点差额、库存差异、差异数量

**盘点联动**：盘点单审核时按差异方向自动生成对应其它出入库单的行为。**盘盈行必须录入非零成本**（防业财偏差：零成本入库会导致物料移动平均成本被拉低）。联动生成的出入库单**用户看不到草稿态**——创建与审核在同一事务中完成。
_Avoid_: 盘点自动生成、盘点出库、盘点入库

### 库存动作（与单据的对应关系）

**盘盈**：实物多于账面库存的差额。**自动生成其它入库单**，库存增加。
_Avoid_: 库存盈余、账面盈余

**盘亏**：实物少于账面库存的差额。**自动生成其它出库单**，库存减少。
_Avoid_: 库存短缺、账面亏损

**期初**：系统初始化时录入的初始库存。**生成其它入库单**，作为库存基线。
_Avoid_: 初始库存、期初余额

**报废**：物料损坏或过期导致的出库处理。**生成其它出库单**，库存减少。
_Avoid_: 损耗、销毁、过期出库

**领用**：办公、样品、测试等非生产性领用。**生成其它出库单**，库存减少。
_Avoid_: 办公领用、内部领用

**归还**：借出物料的归还。**生成其它入库单**，库存增加。
_Avoid_: 退还、回收入库

### 库存指标

**移动平均成本**：每次入库时重新计算物料单位成本的方法（当前库存总成本 ÷ 当前库存总数量）。**仅入库时重算，出库不重算**。
_Avoid_: 加权平均成本、动态平均成本、平均成本

**入库金额**：其它入库单的金额字段，按业务人员录入的"入库单价"计算。预填默认值=当前物料移动平均成本，但允许业务人员手工覆盖（用于录入新的入库成本，如采购价、归还估值）。
_Avoid_: 入库成本、入库总价

**出库金额**：其它出库单的金额字段，按**出库那一刻物料的移动平均成本**自动计算，**不允许业务人员手工指定**。
_Avoid_: 出库成本、出库总价

**成本锁定**：其它出库单审核时锁定物料当时的移动平均成本作为记账依据，**反审核用同一锁定值红冲**（不重新查物料，避免期间被入库改动导致账实不一致）。
_Avoid_: 成本快照、出库成本锁定

**成本变动日志**：每次入库重算移动平均成本时同步记录的轨迹。包含"成本变动前/后、数量变动前/后、变动金额、变动原因（单据类型与单号）"。用于追溯任意物料在某次入库后成本变化的来龙去脉。
_Avoid_: 成本变更日志、成本变动台账

**最后采购价/日期**：物料上跟踪最新一次采购入库的成本与日期。仅作参考，不参与库存金额计算（库存金额始终用当前移动平均成本）。
_Avoid_: 最近采购价、最新进价

**库存总览**：跨仓库的物料库存数量与价值汇总视图。
_Avoid_: 库存看板、库存汇总

**库存台账**：所有出入库流水记录，按物料、仓库、时间维度可追溯。
_Avoid_: 库存明细账、库存流水

**库存预警**：当物料库存低于安全库存时触发的提醒。
_Avoid_: 库存警报、安全库存提醒

### 单据状态

**草稿**：单据已创建未审核。**可编辑、可删除、可审核**。
_Avoid_: 新建、待审核、未生效

**已审核**：单据已审核。**库存数量已变动，不可编辑**，仅可通过反审核回退到草稿态。
_Avoid_: 完成、已生效、已过账

### 业务规则

**库存单向约束**：草稿不锁库存、不影响数量；只有"已审核"才影响库存数量。
_Avoid_: 实时库存、即时库存

**业务日期**：单据上记录的出入库日期（业务发生日期），不等于创建日期。
_Avoid_: 凭证日期、制单日期

**口径提示**：抽屉顶部向用户展示的"业务规则提示"。其它出库提示"库存减少"、其它入库提示"库存增加"，用于防误操作。
_Avoid_: 操作提示、业务说明

### 业务对偶

**盘盈 ↔ 盘亏**：盘点单的两种结果，方向相反、库存影响相反、生成单据类型相反。

**入库（库存 +）↔ 出库（库存 −）**：所有库存变动都可分解为入库或出库；其它出入库单构成对偶的姐妹单据。**业务规则不对称点**：入库金额按业务人员录入值（设计为新成本），出库金额按物料移动平均成本锁定（不允许业务人员覆盖）。其它对称项：自动编码、状态机、批量添加物料。
